# consultingTemplate

Planning and research for a storefront-as-a-service platform: fast Astro sites on
Cloudflare Workers for small local businesses and Etsy, Amazon, and eBay sellers,
built from the CatholicJoe reference architecture (Astro, Workers, D1, better-auth,
Stripe, ShipStation, Cloudflare Email, Mailchimp).

- `reports/` holds the consolidated strategy report.
- `research_notes/` holds the per-topic research notes behind it.

The platform name is not yet decided. See the report for the shortlist and the
verification steps to run before registering a domain.
